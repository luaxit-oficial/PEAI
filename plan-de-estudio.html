Bienvenido a PEAI

Aprende cualquier tema con un plan hecho por IA. Para empezar necesitas una API key gratuita de Groq.

¿Cómo consigo mi API key?
  1. Toca Ir a Groq (abajo) para abrir la consola.
  2. Crea tu cuenta gratis con Google, GitHub o correo.
  3. Entra a la sección API Keys del menú.
  4. Toca Create API Key, ponle un nombre (por ejemplo PEAI) y confirma.
  5. Copia la key (empieza con gsk_). Solo se muestra una vez, ¡cópiala ya!
  6. Vuelve aquí, pégala en el cuadro y toca Validar y entrar.
